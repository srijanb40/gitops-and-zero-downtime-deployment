
# Argo CD GitOps Demo

A production-inspired Kubernetes GitOps reference implementation demonstrating declarative application delivery, environment promotion, Helm-based deployment management and automated configuration reconciliation using Argo CD.

## Project Objectives

* Implement GitOps-based Kubernetes application delivery.
* Manage application deployment configurations using Helm.
* Separate development and production deployment environments.
* Validate Helm charts through GitHub Actions.
* Demonstrate Kubernetes health checks, resource controls and security contexts.
* Establish a foundation for Prometheus-based monitoring and operational visibility.

## Technology Stack

Kubernetes | Argo CD | Helm | GitHub Actions | Docker | Prometheus | Grafana

## Architecture

Developer → GitHub Repository → GitHub Actions → Argo CD → Kubernetes → Application

## Environments

* Development: Automated synchronization and self-healing.
* Production: Controlled synchronization and promotion.
